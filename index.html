Cómo funciona

Tres pasos, cero build

Aurora vive dentro de .nz: no colisiona con Tailwind, Bootstrap ni el CSS que ya tengas.

Enlaza el CSS

Core + nucleo desde el CDN de jsDelivr. Dos links y dentro.

Marca el body

class="nz" activa el sistema. Nada sale del scope.

Usa las clases

Toda la API está en la galería y en INDEX.md. Si no está ahí, no existe.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Ntizar/Ntizar-Aurora@master/ntizar.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Ntizar/Ntizar-Aurora@master/ntizar.nucleo.css">

<body class="nz" data-nz-theme="light">
  <button class="nz-btn nz-btn--primary">Funciona</button>
</body>
